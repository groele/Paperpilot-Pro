# PaperPilot Pro V4.0.7

This release removes the custom Google Scholar sidebar panel that added citation/year/source filtering. The corresponding settings toggle and per-query filter persistence have also been removed, so the plugin no longer changes which native Scholar results are visible.

The citation/year sorting toolbar remains available. Google Scholar's own filter controls remain intact. PaperPilot Scholar's journal highlighting, badges, duplicate grouping, citation tools, DOI actions, and other item controls are unchanged.

This is a patch release. No stored library or citation data schema changed.
