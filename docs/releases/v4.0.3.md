# PaperPilot Pro V4.0.3

文献库重新以按阅读日期展示的热度日历为默认视图。

- 打开插件即可看到阅读统计、四周日历、每日文献数量和连续阅读天数；点击“收起日历”可腾出空间。
- 点击日期或用键盘 Enter/空格选择日期，筛选当天文献；点击同一天或“重置显示全部”解除日期筛选。搜索、收藏、笔记和排序继续可用。
- 保留原有热度面板设置。未知阅读时间不计入今天，日期格的星期按本地日期计算；近三天和本周筛选显示正确的范围及数量。
- 保留 V4.0.2 的原生工具栏弹窗尺寸修复。

`npm run verify` 通过静态检查、130 项测试和 E2E fixtures。浏览器检查覆盖日历默认可见、28 个日期格、键盘筛选、重置、折叠重开及范围数量。原生工具栏弹窗在受控 Chromium 中连续关闭重开三次，检查浅色/深色、热度展示、未知时间记录、搜索与列表滚动、功能与设置操作。

更新解压目录后，在 `chrome://extensions` 重新加载 PaperPilot Pro。保留文献库与设置；GitHub 历史 Release 和标签保留。
