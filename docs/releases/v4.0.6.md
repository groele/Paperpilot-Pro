# PaperPilot Pro V4.0.6

系统可靠性修复，延续 V4.0.5 的精简浅色卡片与默认阅读热度。

- 输入立即保存，关闭工具栏弹窗不再丢失最后编辑；迟到的失败回退不能覆盖新输入。
- 缓存合并刷写结算全部等待者；删除、替换、凭据改变与迟到响应按代次隔离，旧请求不能恢复已清缓存。缓存 schema 更新为 5。
- DOI 扫描完整性参与身份判定，避免预算外冲突被隐藏；保留权威后缀中的标点与 Unicode 字符，并统一文献库 DOI 查询规则。
- PDF 候选去重保留签名参数编码与资源大小写；修正网页 URL 比较和超范围导入日期；失败日志不写凭据查询串。
- 删除旧输入保存防抖分支和重复 URL 比较函数，保留已有设置、文献与笔记，以及 GitHub 历史版本。

验证：169 项测试、E2E fixtures、24 组真实扩展检查（25 个 DOI 页面场景）、三次原生工具栏弹窗重开与立即关闭输入保存。完整问题、复现和验证边界见 [系统审查报告](../system-audit-2026-10-12.md)。

安装后在 `chrome://extensions` 重新加载扩展并刷新论文页面。已有安装不会被强制恢复默认。
