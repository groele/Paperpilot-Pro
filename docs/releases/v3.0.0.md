# PaperPilot Pro 3.0.0

## Overview

Version 3.0.0 brings explicit control of academic analysis to Dashboard Overview, with synchronized settings, cancellable streaming, responsive reading cards, and clearer evidence boundaries. It also includes citation-export, metadata-cache, authentication-page detection, and service-worker reliability improvements from the working tree.

This version is a requested major product milestone. It does not intentionally introduce a breaking storage schema, configuration key, or public message API change.

## Changes users will notice

- Toggle Academic Analysis from Dashboard Overview or global settings. Open journal pages update immediately.
- Select one of five built-in perspectives or a custom prompt, then click Generate. Selecting a perspective alone no longer starts a request.
- Stop generation without losing received text. Disabling analysis, disabling the card, or leaving the article cancels active work.
- Analysis requires an abstract and distinguishes reported evidence from inference. Copied partial results are identified as incomplete.
- Popup and journal-card contents remain scrollable in narrow or short windows. Keyboard controls, visible focus, and reduced-motion preferences are supported.
- Default perspectives are restored, custom prompts are preserved, failed core-setting saves roll back, and clipboard copying no longer recurses.

## Configuration and data compatibility

- `enable_ai_summary_btn` remains the analysis feature key, including for existing installations with the feature disabled.
- `ai_preset`, `ai_prompt`, provider credentials, and reading-history formats are retained.
- No data migration or new browser permission is required.
- The existing manifest declares Chrome 100 as its minimum. Release smoke tests use a current Chromium build; the full range of older supported browser versions was not retested.

## Upgrade

1. Export a reading-history backup from your current installation before replacing an unpacked extension folder.
2. Download `paperpilot-pro-3.0.0.zip` and extract it into the existing extension directory, keeping its path and browser profile unchanged.
3. Reload the extension on the browser extensions page, then refresh existing article tabs.
4. Confirm your AI provider settings, enable the journal card and Academic Analysis, select a perspective, and click Generate.

Do not uninstall the existing extension if you want to retain its local settings and history. Loading the package as a separate extension may create a different storage identity.

## Validation

- `npm run verify`: static checks, 65 Node tests, and routing/performance fixture checks pass.
- `npm run test:browser`: 13 groups of scenarios pass with the actual MV3 extension in an isolated Chromium profile.
- Real service-worker HTTP streaming is exercised against a local SSE provider: completion, cancellation, error, empty response, and retry.
- Light/dark popup views at 420x600 and 320x480, and journal cards at 1100x800 and 320x480 are checked.
- Storage-error handling is tested using an injected failure; third-party metadata requests use controlled failure responses.
- The release archive contains runtime files and documentation only, excluding tests, developer scripts, browser profiles, and local settings.

## Known limits

- Tests do not certify every live publisher login/download path or every remote AI provider.
- The full 45/180-second UI/request deadlines were not each exhausted in browser tests; cancellation of a stalled reader has a targeted regression test.
- Analysis receives titles and abstracts, not full papers. Novelty, methods, numerical claims, and limitations still require verification against original sources.
- Nature Index matching still needs a separately validated, source-dated journal/ISSN dataset; broad name matching can misclassify journals.

## Rollback

Keep a copy of the previous extension directory and the exported history backup. To roll back an unpacked installation, restore that directory at the same path and reload the extension. Existing storage schemas are retained by this release, but a backup remains the recovery source if a separate installation or profile is used.
