# PaperPilot Pro V4.0.1

修复 V4.0 设置开关与页面实际行为不一致的问题，并改善设置页可读性。

- **偏好设置 → 引用格式**：提供“显示学术引用格式区域”总开关，以及 GB/T 7714、BibTeX 独立开关。总开关关闭时保留子开关偏好；两个按钮都关闭时不显示空引用区块。
- 修复期刊网页入口、Scholar 国标引用和收藏按钮关闭后仍显示的问题。更改设置会同步到已打开页面，刷新后保持有效。
- 恢复原版标题字体、字号与渐变，保留分类、卡片折叠和场景预设。分类不再需要横向滚动；场景预设可折叠，设置文字更易读。
- 搜索覆盖所有分类；清空后回到原来选择的分类。支持分类键盘导航；窄窗口不会裁掉右侧开关。
- 设置保存失败时恢复已保存的开关状态。更改引用显示不会中断进行中的 AI 分析。
- 修复升级后部分开关重新开启、重复备份 ID、无 DOI 同名版本混并、收藏超过容量时被丢弃、清空失败时状态变化、PDF/元数据正文超时和 AI 空响应误报成功等逻辑问题。
- 恢复 Scholar 排序与筛选工具及其开关，保存每个检索的筛选偏好；统一 AI 与期刊匹配实现，清理失效旧界面和本地旧安装包。

验证使用真实 Chromium MV3 扩展运行时、受控论文/Scholar 页面及本地 AI 流服务，覆盖开关、重载、预设、失败恢复、连续设置更新、Scholar 排序筛选、320/420 像素窗口和深浅色截图，共 21 个检查组。`npm run verify` 通过静态检查、130 项测试和 E2E fixtures。详细问题和清理范围见 [逻辑审查报告](../quality-audit-2026-10-12.md)。受控页面测试不等于逐一验证所有线上出版社网站。

更新扩展后，请刷新原先已经打开的论文和 Scholar 页面，让页面加载新的内容脚本。原有文献库和设置保留；V4.0.0 标签与安装包不覆盖。
