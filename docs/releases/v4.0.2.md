# PaperPilot Pro V4.0.2

修复 Chrome 工具栏点击插件后只出现极小弹窗、无法使用功能和设置的问题。

V4.0.1 在根元素上使用 `max-width:100vw` 和 `height:min(600px,100vh)`，导致 Chrome 原生 action popup 的初始小视口反过来限制内容的固有尺寸。真实工具栏弹窗实测为 25×25 像素；此前的扩展标签页检查没有覆盖这个入口。

- 原生工具栏弹窗恢复固定固有尺寸，不再由初始小视口限制根尺寸。
- 内部容器根据实际可用高度布局，功能、导航和设置保持可操作。
- 单独打开的扩展标签页继续支持窄窗口布局。
- 增加原生弹窗回归：通过 Chrome action API 打开插件、连接实际弹窗 CDP target、执行鼠标操作、保存设置、关闭后重开。三次验证通过，测试环境实际可用尺寸为 435×510 像素，底部设置可滚动到达。

`npm run verify` 通过静态检查、130 项测试和 E2E fixtures；`npm run test:browser` 覆盖既有 21 组检查及新增的三次原生弹窗检查。检查在受控 Chromium 配置中完成，不等于检查用户当前已安装的 Chrome 配置。

更新解压目录后，请在 `chrome://extensions` 重新加载 PaperPilot Pro，再点击工具栏图标。若使用安装包，请加载解压后含 `manifest.json` 的目录。原有文献库和设置保留；GitHub 历史 Release 和标签不覆盖。
