# PaperPilot Pro V4.0.5

默认卡片调整为用户截图中的浅色精简阅读状态：保留期刊／标题／明确年份、Nature Index、PDF 候选提示、DOI 复制和网页入口；默认关闭引用区、指标区、下载按钮与 AI 区。阅读热度继续默认展开。

- 统一首次安装、读取和预设的默认值，升级保留已有主动设置、文献、笔记及密钥。已有安装可选择“常用推荐”或“恢复默认”应用新样式。

- 同步外部热度设置；自动指标查询检查当前开关和凭据，丢弃失效的排队任务与响应。
- 防止扫描边界截断 DOI 后仍错误赋值。

验证：157 项测试、E2E fixtures、23 个 DOI 页面场景与既有浏览器流程；原生工具栏弹窗三次重开。默认卡片截图和失败路径在真实 Chromium 扩展环境中检查。详见 [默认态与逻辑审查](../defaults-and-logic-audit-2026-10-12.md)。
