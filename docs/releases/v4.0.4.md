# PaperPilot Pro V4.0.4

进一步加强 DOI 识别，重点减少错误归属和冲突时的误选。

- DOI 元数据、JSON-LD、当前页面／出版社路径及正文标识按来源选择；重复标签不再直接取第一个，独立证据不能消歧时保留待识别。
- JSON-LD 识别 mainEntity 图谱中的当前文章，保留 URL 查询参数，排除标题不匹配和同分冲突节点。
- 排除按标题标出的参考文献区、行内引用与隐藏 DOI；正文优先采用明确的文章标识和 DOI 标签。
- 补充编码前缀、嵌套编码链接、部分坏转义、不间断空格和 Unicode 实体。保留显式 DOI 的合法字符及旧式 SICI 标识，避免二次解码，拒绝损坏的 UTF-16 和单字段多 DOI。
- 按 DOI Handbook 的 ASCII 大小写规则统一身份比较、文献去重、请求合并和缓存；非 ASCII 字符不会被错误合并。
- 在线元数据及标题解析后的 PDF 查询必须返回匹配的 DOI。元数据缓存版本更新，旧识别结果会重新获取；文献库与笔记保留。
- 保留 V4.0.3 默认展开的阅读热度日历及工具栏弹窗尺寸修复。

验证：`npm run verify` 通过静态检查、149 项测试及 E2E fixtures。真实 Chromium MV3 检查包含 22 个 DOI 页面场景和既有交互回归；原生工具栏弹窗连续关闭重开三次。在线 Crossref 抽查两条 DOI 与登记结果一致；另一条请求遭遇 429 限流，未算作已核实。合成测试 DOI 不代表实际登记，未宣称全站识别率。

规则参考：[DOI Handbook](https://www.doi.org/doi-handbook/DOIHandbook_2025.pdf) 与 [Crossref 对 DOI 正则及标点误识别的说明](https://www.crossref.org/blog/dois-and-matching-regular-expressions/)。详细审查见 [DOI 识别记录](../doi-recognition-2026-10-12.md)。

更新解压目录后，在 `chrome://extensions` 重新加载插件，并刷新已打开的论文页面。GitHub 历史 Release 和标签保留。
