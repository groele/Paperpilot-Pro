## 已复现的问题

| 问题及触发条件 | V4.0.5 行为 | V4.0.6 处理与证据 |
| --- | --- | --- |
| 输入后立即关闭工具栏弹窗，无 blur/change | 500–700 ms 保存计时器随页面销毁，最后输入丢失；对照原生测试超时 | input 事件立即提交本地保存，仅延迟成功提示；真实原生输入后立即关闭、连续三次重开均保留值 |
| 保存失败的回退读取晚于下一次成功输入 | 旧读取可能覆盖新输入 | 输入保存及回退绑定修改序号；真实扩展延迟失败回退，不覆盖新保存的目录 |
| 同时请求两次缓存刷写 | 取消第一定时器后，第一 Promise 永不完成 | 合并全部等待者，成功／失败／取消均结束；存储失败可重试 |
| 删除缓存或慢读取期间清空缓存 | 删除事件被忽略；旧读取恢复被清空的数据 | 删除／替换推进缓存代次；旧读取不能覆盖当前状态；单测及真实浏览器存储事件验证 |
| 清缓存／换凭据时已有元数据请求在途 | 旧请求可能回填结果；新请求仍加入旧任务 | 请求合并键包含代次，提交前检查代次；旧响应返回明确失效状态，新的请求独立执行；真实 worker 延迟供应商响应检查 |
| 自己的缓存写入事件晚于其他论文结果完成 | 旧序列化快照可能替换内存对象，丢掉新结果 | 识别自己已提交的写入事件；相同内容跳过写入，避免无事件的陈旧标记；保留后来完成的记录 |
| 第 129 个结构化标识与前 128 个冲突，或深度越限 | 看似唯一的首个 DOI 被接受 | 解析结果携带扫描完整性；不完整的最高优先级证据拒绝赋值，低级不完整证据不能消歧；浏览器冲突元数据检查 |
| 显式 DOI 后缀包含引号、未配对括号、Unicode 连接字符或 URL 字样 | 清理把合法后缀当成正文标点／包装 | 完整权威标识保留后缀；自由正文仍清理外部包装；测试原始标识和编码解析链接往返一致 |
| 文献库使用含 Á／á 的 DOI 查询 | 搜索去重音、Unicode 小写与 DOI 身份规则不一致，可能漏查或混查 | DOI 查询按 ASCII 折叠，普通标题／作者仍支持重音无关搜索；验证完整、部分、字段、未限定及解析器链接查询 |
| 候选去重通过 URLSearchParams 删除参数 | `A%20B%7e%2f` 被改写为 `A+B%7E%2F`，无值 flag 变为 flag= | 按原始查询段去除追踪参数，保持功能／签名参数字节；路径与参数大小写不同的资源保留独立身份 |
| 网页 URL 比较将整个路径／参数转成小写并删除尾斜线 | 区分大小写的资源、协议或路径可能被视为同一页 | 用 URL 的标准主机归一化，保留协议、路径、尾斜线和查询参数；只忽略片段 |
| 导入 time=1e20 或超长数字时间 | 有限数被视为有效时间，但 Date 无效 | 同时检查 Date 有效范围，未知时间保留未知；原生日历加入无效时间样本，今日计数仍为 2，网格无 NaN |
| 元数据失败日志包含带密钥／邮箱的完整 URL | 调试日志可能保留凭据查询串 | 仅记录供应商 origin 和错误类型；构造包含完整凭据 URL 的异常，确认日志不含查询信息 |

## 实现与清理

移除实际保存的输入防抖计时器及 easyScholar 重复保存分支；所有输入采用同一即时保存路径。网页入口比较复用 URL 身份函数，删除另一份大小写不敏感的旧辅助函数。缓存刷新队列统一结算，不保留被取消任务的悬空等待者。元数据缓存 schema 从 4 更新为 5，让旧算法结果按需重新获取，不迁移或删除阅读记录。

发布从独立且与远端一致的 checkout 完成，只包含本轮修改。原工作区未归属本轮的图标、PDF fixture、忽略规则修改保留，不打入发布提交。dist 保留当前安装包；GitHub 的历史 Release 和标签继续保留。

## 回归范围

- `npm run verify`：静态检查、169 项测试及 E2E fixtures。
- `npm run test:browser`：24 组真实扩展检查，包含 25 个 DOI 页面场景；受控供应商失败／迟到响应、输入失败回退、截图默认态、NI／DOI／引用开关、SPA 论文切换、AI 流式生成／停止／关闭／失败／重试、无摘要限制、文献库并发编辑／撤销／备份／导入／筛选、Scholar 去重与来源／排序控件。
- `npm run test:popup`：原生 action popup 三次关闭重开，实测 435×510；底部设置可达、无横向溢出、四周日历 28 格、未知／无效时间不计入今日；使用原生 Input.insertText 输入后立即关闭，保存值在下一次打开时一致。
- 最终 ZIP 比对每个文件与发布源码，再对解压安装包执行原生弹窗检查；发布后下载 GitHub 资产，比对 SHA-256 和字节内容。

## 验证边界

上述页面、供应商故障和输入均为受控场景，在真实 Chromium 扩展运行环境中执行；没有访问或更改用户的 Chrome 配置、真实文献数据和服务密钥。本轮没有重新逐站验证所有出版商登录流程，也没有以真实付费 AI／学术 API 账户做全量联网测试。DOI 识别结果仍受页面提供的证据限制；冲突或超出安全扫描预算时宁可不赋值，不能承诺所有网站零误识别。

升级后在 `chrome://extensions` 重新加载插件并刷新论文页。新安装沿用截图默认态；已有安装保留主动配置，需要采用精简默认时可选择“常用推荐”或“恢复默认”。
