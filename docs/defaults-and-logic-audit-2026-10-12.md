# V4.0.5 默认态与逻辑审查

日期：2026-10-12。依据用户提供的完整卡片截图，检查首次安装、升级、默认读取、预设、开关同步、论文身份、DOI/PDF/年份及异步失败路径。

## 默认显示

新安装使用浅色卡片，保留品牌／期刊、Nature Index 标识（仅匹配期刊且开关开启时）、明确发表年份、论文标题、PDF 候选提示、单一 DOI 复制按钮和网页入口。默认关闭期刊引用格式区域、指标抽屉、PDF 下载按钮、AI 区和页面诊断。下载按钮关闭不影响 PDF 候选识别；候选提示不等于已经通过文件校验。

文献库的阅读热度、统计与快捷筛选继续默认开启。使用 `core/settings.js` 统一 40 个默认偏好；首次安装、公共读取和弹窗读取使用相同定义，“常用推荐”与“恢复默认”复用同一功能配置。工具栏展开状态是独立布局偏好，应用预设不强制改变。极简／专家预设保留主题、固定状态及独立 easyScholar 启用选择。

已有安装升级只补全缺失的键，不覆盖已保存的开关、主题、文献、笔记和密钥。已有用户如需采用截图样式，可在偏好设置的配置预设中选择“常用推荐”或“恢复默认”；这两个预设不删除文献或修改 API 配置。

## 发现与修复

| 问题 | 原影响 | 修复 | 验证证据 |
| --- | --- | --- | --- |
| 安装、读取回退、推荐／恢复默认多份定义 | 新安装与重置显示不同；缺失键倾向全部开启 | 统一默认契约，精简阅读为初始态 | 新安装及升级单测、真实扩展默认卡片 |
| 升级已有设置与新默认态的边界 | 新默认可能覆盖旧偏好 | 初始化仍只写缺失键 | 保留主动启用的 AI／引用／PDF、暗色、密钥及笔记 |
| 年份缺失自动使用当前年 | 未知论文显示虚假年份并进入引用 | 缺失年份为 null，显示“年份未标注”；不以修改时间冒充发表时间 | 有日期／无日期卡片对照 |
| `citation_pdf_url` 元数据名称含 citation | 标准正文 PDF 元数据被当成引用附件过滤 | 元数据名称与可见链接标签分开，保留正确来源 | 仅含 PDF 元数据的单测和默认卡片 PDF 候选提示 |
| Nature Index 总开关未进入期刊卡读取／重绘 | 关闭后卡片仍显示 NI 标识 | 补全读取、渲染条件及同步 | 开关切换后实时移除／恢复标识 |
| DOI 快捷键绕过按钮开关 | 关闭后 Alt+C 仍会复制 | 快捷键与可见按钮共用功能门控 | 关闭时剪贴板调用次数为零 |
| DOI 操作重复，缺失 DOI 时按钮复制引用 | 同一 DOI 两个入口，按钮名称与结果不一致 | 保留单一行内 DOI 复制；删除旧动作及回退处理 | 默认卡片及无 DOI 页面检查 |
| 固定操作忽略保存结果 | 保存失败仍提示成功，外观与存储不一致 | 检查响应、禁用重复点击、恢复固定状态和位置 | 真实扩展内容脚本注入保存失败 |
| 多个复制动作未处理拒绝 | 剪贴板权限失败产生未捕获异常 | 标题／DOI／GB／Bib 错误提示，不记录假成功 | 剪贴板拒绝和备用复制失败；无页面异常 |
| 异步回调使用可变全局论文／卡片 | 路由切换后可能给另一篇论文记录操作或更新错误卡片 | 绑定卡片及书目信息快照，下载事件传递原论文上下文 | 延迟复制后更换 SPA 论文，记录只落在原 DOI；新卡片不显示复制成功 |
| 预设失败只恢复部分复选框 | 主题与总览状态可能保留失败目标 | 恢复请求涉及的输入、主题、总览及布局，避免重置无关偏好 | 失败预设恢复暗色、AI／引用及关闭的热度面板 |
| 外部修改视图开关未重排弹窗 | 复选框变化，但热度／统计仍显示旧状态 | 存储事件应用受影响布局 | 外部关闭热度即时同步 |
| 自动指标开关未约束后台调用与排队任务 | 关闭后仍可能调用服务或应用旧凭据响应 | 自动查询显式标记；请求前后重读开关／凭据，区分主动查询 | 禁用后排队请求未发出，密钥变更后的迟到响应丢弃 |
| DOI 标签在扫描边界被截断 | 不完整后缀会被当成完整 DOI | 放弃被截断的末尾词；修复单文本多候选上限 | 2500 字符后缀页面不错误赋值；候选数上限检查 |

## 检查结果与范围

- `npm run verify`：语法、版本、路由检查；157 项测试；E2E fixtures。
- `npm run test:browser`：真实 Chromium MV3，新增初始截图状态和异常路径，23 个 DOI 场景，已有引用、AI、搜索、文献操作、Scholar、主题及窄窗口回归；原生工具栏弹窗连续关闭重开三次。
- 默认卡片实际截图在 `output/playwright/default-card-reference.png`，采用用户截图中的字段作为受控展示数据。
- 保存／剪贴板故障和异步路由切换在扩展隔离世界中测试，不用普通网页的替身模拟扩展 API。
- 最终安装包与发布源码逐文件比较；解压包再验证原生弹窗。

没有把这些检查解释为“所有页面绝无逻辑错误”。个人 Chrome 配置、所有出版商登录／付费下载路径和在线指标服务仍受实际环境约束。未知年份／DOI 不猜测补齐；PDF 候选仍需下载时校验；指标需要明确启用服务并配置凭据。
