## 二、学术分析的实际行为

1. 在 Dashboard Overview 点击“学术分析视角”即可启停；全局配置同名选项同步。
2. 元卡关闭时保留分析偏好，Overview 提示需要开启元卡，不自动改变另一项设置。
3. 开启分析只显示入口；选择视角也不自动发送请求。点击生成后发送标题与摘要至用户配置的服务。
4. 支持极速速读、创新贡献、技术路线、局限批判、术语精讲和自定义提示词。
5. 停止、切换视角、关闭功能、关闭元卡或离开页面都会结束相应活动请求。收到的部分结果可保留；导出会标明未完成。
6. 无摘要时不生成。结果及复制笔记明确说明依据为标题与摘要，不代表通读全文或已核实结论。

## 三、验证证据与边界

- `npm run verify`：静态检查、65 项 Node 测试、路由/性能夹具全部通过。
- `npm run test:browser`：真实 Chromium 中加载原始 MV3 扩展，13 组场景通过，未捕获页面异常。
- 浏览器使用全新隔离配置；本地 HTTP SSE 服务完整经过扩展 service worker 和 core/ai 流式读取链路。
- 测试中共发出 6 次本地生成请求，观察到 2 次慢请求被客户端终止；不使用个人密钥或付费 AI 服务。
- 第三方元数据在烟测中使用受控 503 响应，以保持验证独立、可重复。模拟存储错误仅用于验证回滚。
- 已检查生成的亮色/暗色和窄屏截图；原有 `test:e2e` 仍是夹具检查，新增 `test:browser` 才是实际浏览器回归。
- 未完成所有真实出版社登录态、付费 PDF 下载、远程 AI 提供商、Chrome 原生工具栏弹出窗口的逐项验收。浏览器测试打开实际扩展 popup 页面并设定相应视窗。
- 45/180 秒超时阈值未在浏览器中逐个等待耗尽；中断与错误恢复链路已实测，底层 stalled reader 的主动取消有单独回归。

## 四、仍值得继续完善的工作

以下是本次审查中未扩大实施的独立事项，不应把本次通过理解为全部站点/数据源已经验证。

| 优先级 | 建议 | 原因与验收标准 |
|---|---|---|
| 高 | Nature Index 期刊识别统一到带来源/年份的规范数据集 | journal.js 的 checkNatureIndexMatch 仍按 nature、science、physical review 等子串匹配；与 Scholar 内置列表不一致，有误标风险。应核对官方名单、ISSN 和别名，增加近似刊名反例。 |
| 高 | 增加真实出版社适配矩阵 | 分别验收 Nature/Science/ACS/Wiley/Elsevier/机构仓储的开放页面、登录页面、PDF 直链、SPA 切换；当前夹具覆盖不能替代真实站点。 |
| 中 | 元数据来源与年份更显式展示 | IF/分区/被引量属于不同数据口径；建议逐项带来源、年份和缓存时间，并确保未知值不变成推测排名。 |
| 中 | 扩大 AI 流式协议回归 | 当前本地服务验证 OpenAI-compatible SSE；其他提供商分别补充真实连接、事件差异、限流、畸形 JSON、超长文本与重连验收。 |
| 中 | 提供 AI 配置完整性说明 | 模型默认值与可用性由提供商决定；在 UI 中区分“功能开启”“配置完整”“连接已测试”，避免以启停状态代表服务可用。 |
| 中 | 历史记录的大数据量和多窗口并发验收 | 后续用千条/万条记录及跨窗口编辑验证分页、搜索、导出、冲突反馈和存储故障恢复。 |
| 低 | 更完整的无障碍审计 | 本次补齐主要键盘入口与状态反馈；后续覆盖所有弹层焦点返回/锁定、对比度和读屏标签。 |
