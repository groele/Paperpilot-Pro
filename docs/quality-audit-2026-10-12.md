# V4.0.1 逻辑审查与旧代码清理

## V4.0.5 追加：截图默认态与逻辑检查

统一精简阅读默认态并保留升级偏好；修复年份、PDF 元数据过滤、开关／快捷键门控、失败回退、外部布局同步、异步论文身份和指标任务凭据检查。详见 [完整审查报告](defaults-and-logic-audit-2026-10-12.md)，包含逐项问题、影响、修复和验证范围。

## V4.0.4 追加：DOI 精度与身份一致性

审查发现重复 DOI 元数据、JSON-LD 同分节点及 URL 参数冲突仍会取第一个候选；无标记参考文献段落、行内引用和隐藏节点会影响正文回退。改为来源分级与独立证据消歧，无法消除冲突时不猜测。JSON-LD 解析包含 mainEntity 图谱归属，保留页面查询参数，限制深度、节点与文本预算。

共享解析器补充编码前缀、嵌套编码链接、坏转义并存、不间断空格和补充平面 Unicode 实体；显式 DOI 保留合法字符，单一标识字段拒绝多个 DOI。依据 DOI Handbook 使用 ASCII 大小写折叠，避免误合并非 ASCII 标识；缓存和请求合并同时修正。供应商返回必须匹配请求的 DOI，包括标题识别后的 Unpaywall；元数据缓存版本升级为 4。

验证包含 149 项测试、22 个真实扩展 DOI 页面场景及原生工具栏弹窗三次重开。在线 Crossref 抽查两条 DOI 与登记身份一致；第三条请求返回 429，未计为核实成功。详见 [V4.0.4 修复说明](releases/v4.0.4.md)。

## V4.0.3 追加：按阅读时间展示热度

恢复默认展开的四周阅读日历与阅读统计，保留手动收起和原有热度面板开关。日期格改为键盘可操作的按钮，未来日期禁用；星期按本地日期计算。未知阅读时间不再计入今天。日历筛选提示与列表共享日期筛选结果，近三天和本周正确显示范围名称及数量。

浏览器检查覆盖默认显示、28 个日期格、键盘日期筛选、重置、折叠重开及范围数量。原生工具栏弹窗检查覆盖浅色/深色、三次重开、未知时间不计入今日，以及搜索和列表滚动可达。

## V4.0.2 追加：工具栏弹窗入口

用户反馈 Chrome 点击插件图标后弹窗极小。直接调用 `chrome.action.openPopup()` 并附加到真实 action-popup target，复现了 25×25 像素尺寸。原因是 V4.0.1 的窄窗口修复在根尺寸中使用视口单位，使原生弹窗的初始视口限制了它自己的固有尺寸。此前 21 组浏览器检查使用扩展标签页，未覆盖该原生入口。

V4.0.2 为 action popup 保持固有根尺寸，视口限制仅应用于内部容器；独立扩展标签页使用单独的响应式根规则。新增 `scripts/native-popup-smoke.js`，用 Chrome action API、CDP 实际鼠标事件验证功能开关、进入设置、引用开关保存、底部设置可达，以及连续三次关闭重开。原生测试实测 435×510，均通过。浏览器回归命令现包含这项检查。

## V4.0.1 审查记录

本次检查以当前运行路径为依据，覆盖 manifest 的静态注入、动态激活、设置读取/保存/广播、DOI 和元数据、文献身份、历史队列、导入导出、PDF 验证、AI 调用及 Scholar 页面生命周期。下表中的修复已通过对应回归测试。

| 问题 | 实际影响 | 修复与验证 |
| --- | --- | --- |
| 期刊 GB/Bib/网页入口、Scholar GB/收藏开关未完整读取 | 关闭开关后按钮仍显示 | 接通读取和实时刷新；浏览器分别关闭、重开、重载验证 |
| 更新扩展时读取的设置清单小于默认清单 | 已关闭的功能在升级后重新开启 | 从默认清单生成读取列表；测试保持引用、收藏、统计关闭偏好 |
| 备份可包含重复 ID，身份比较曾直接相信 ID | 编辑/删除定位不唯一，甚至合并不同论文 | 身份比较按书目信息；统一修复重复 ID，保留已有合法 ID；单测覆盖复制 ID 和预留 ID 冲突 |
| 无 DOI 的同名访问会匹配多条不同 DOI 文献 | 后台再访可能合并并删掉不同版本 | 优先精确 DOI，歧义时保留独立记录；同名歧义笔记拒绝猜测归属 |

| 元数据超时只覆盖响应头 | JSON 正文停滞导致元数据请求不结束 | 响应体解析包含在同一超时范围，回归测试停滞 JSON |
| AI 连接测试把空响应替换成 OK，摘要路径也可报成功 | 用户看到虚假的连接/分析成功 | 空响应明确失败；连接和非流式摘要统一使用 core/ai.js |
| 切换引用显示时移除 AI 节点并取消请求 | 正在生成的内容中断 | 保留分析节点及绑定；验证连续设置更改和真实本地 SSE 请求 |
| Scholar 排序筛选设置未接通、读取偏好函数未调用 | 工具栏/筛选不可用，偏好不能恢复 | 独立开关、初始化和跨查询恢复；浏览器验证排序、阈值、重载、关闭/恢复和工具栏修复 |
| 固定宽度、分类横滚、分类限制搜索 | 窄窗口裁掉开关，已有开关难找 | 保留原版设置卡片与字体风格；分类两行排列；全局搜索；320/420px 深浅色检查 |

## 清理范围

- 删除后台重复的 AI 默认配置、provider HTTP 分支、旧提示词、备用非流式实现及旧摘要分支，统一由 core/ai.js 提供。
- 删除 Scholar 和期刊页各自的旧 Nature Index 匹配规则；静态/动态注入均加载共享匹配模块。
- 删除不可见的旧搜索标题、计数/切换处理及相关样式；高级筛选保留原生 details 入口。
- 删除没有调用的 Scholar 定时 watchdog 和对应状态，使用现有 DOM observer 修复工具栏。
- 删除 popup 的独立 localStorage 预览存储分支，Chrome 扩展存储和后台队列为唯一数据来源。
- 删除运行期间重复的旧 DOI 开关兼容分支；仅在升级初始化时迁移旧值，并移除旧键，保留独立开关值。
- 移除本地 dist 中旧 3.0.2、4.0.0 安装包，只保留当前 4.0.1 构建。GitHub 旧 Release、标签和 Git 历史按用户选择保留。历史审查文档保留作记录，不作为当前使用说明。
- 不覆盖工作区原有的 `.gitignore`、`lib/svg-icons.js` 和 PDF fixture 修改；发布只携带本次审核过的修复。

## 验证与边界

- `npm run verify`：静态依赖和重复 ID 检查、130 项 Node 测试、E2E fixtures。
- `npm run test:browser`：真实 Chromium MV3 扩展运行时，21 个检查组，包括独立引用开关、总开关、重载、预设、存储失败、取消与连续显示更新、Scholar 排序过滤与偏好、编辑/并发新增/删除撤销、原生 JSON 下载与导入、清空失败、窄窗口和无未捕获异常。
- 测试中的元数据/Scholar 页面和 AI 流服务为受控 fixture。本次未逐一验证全部线上出版社页面、所有云端 AI 模型和登录机构的 PDF 下载路径；因此结论限定为已审查和测试覆盖的逻辑。
- 新包按每个文件与审核来源比较，并检查 manifest、popup、README、package 版本一致。更新扩展后需刷新原先打开的论文和 Scholar 页，加载新内容脚本。
